# Kleiderspenden-Registrierung

Fallstudie im Modul **Programmierung von Webanwendungsoberflächen (IPWA01-01)**.

Die Webanwendung ermöglicht die Registrierung von Kleiderspenden für den fiktiven gemeinnützigen Verein **HilfeDirekt e.V.**.

## Funktionen

- Auswahl zwischen persönlicher Übergabe und Abholung
- Auswahl der Kleidungsart
- Auswahl eines Krisengebiets
- Eingabe einer Abholadresse
- Prüfung des Einzugsgebiets anhand der Postleitzahl
- Bestätigungsseite mit den Registrierungsdaten
- Responsive Darstellung für Desktop, Tablet und Smartphone

## Technologien

- HTML5
- Bootstrap 5
- JavaScript
- GitHub Pages

## Projektstruktur

- `index.html` – Registrierungsseite
- `script.js` – Formularlogik und Validierung
- `bestaetigung.html` – Bestätigungsseite
- `bestaetigung.js` – Anzeige der Registrierungsdaten
- `hilfedirekt-logo.png` – Logo des fiktiven Vereins

## Live-Demo

Die Anwendung ist über GitHub Pages veröffentlicht.
